# Ikon-magyarázó

A koinóban használt ikonok jelentése, aszerint csoportosítva, hol találkozol
velük. (Ugyanaz az ikon néha más helyen más dolgot jelöl — a környezet mutatja.)

## Fő menü (☰)

| Ikon | Jelentés |
|---|---|
| 🔍 | Keresés |
| 🗺️ | Struktúra nézet |
| ↕️ | Rendezés |
| 🔔 | Értesítések / értesítési beállítások |
| ✏️ | Új gondolat létrehozása |
| 🏷️ | Új kategória létrehozása |
| 🧩 | Új gondolat típus létrehozása |
| ✉️ | Meghívóim |
| 🌟 | Tudatpontok |
| ⚙️ | eember beállítások |
| 🚪 | Kijelentkezés |
| 🚧 | Fejlesztés alatt (még nem elérhető) |

## Kártya-menü (műveletek)

| Ikon | Jelentés |
|---|---|
| 🌿 | Javaslat létrehozása |
| 🗳️ | Szavazat leadása |
| 🌟 | Tudatpont módosítás |
| ℹ️ | Részletes adatok |
| ⚖️ | Küszöb érték javaslat |
| 🔔 | Értesítési beállítások |
| ✏️ | Új gondolat létrehozása (az adott entitás alá) |

## Entitástípusok

| Ikon | Jelentés |
|---|---|
| 📄 | Gondolat |
| 🏷️ | Kategória |
| 🧩 | Gondolattípus |
